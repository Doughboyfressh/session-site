SESSION visitors & daily active users

implementationdaily-activity · 2026-10-03 · requested dashboard measurement

Goal

Show measured visitors today and verified daily active users inside SESSION's private developer dashboard. Verify anonymous and signed-in foreground visits, deduplication, UTC rollover, unavailable states, and live operator access.

Non-goals

  • No historical reconstruction or creator-profile counts presented as visitors.
  • No private music, messages, search queries, IPs, or account identifiers sent to Vercel Analytics. Existing Vercel page views continue separately.

Screens & flows

UTC calendar days; current day remains partial.

Private Audience section

Visitors and DAU cards plus an accessible fourteen-day history. Earlier unmeasured days and collector failures have explicit states.

Foreground collection

Bodyless same-origin pings on visible entry, navigation, and throttled interaction. Server verifies identity and issues a signed daily cookie.

Tasks

#TaskEst
1 Append-only SQLite and forward PostgreSQL schema, privacy-preserving daily deduplication, bounded private reads, and API checks. backend
2 Foreground client, dashboard cards/history, lifecycle and mobile checks, both builds, independent review, live deployment. UI / release

Risks

MEDVisitors are browser estimates: clearing cookies, multiple browsers, blockers, and simultaneous first visits affect deduplication. DAU requires a verified signed-in account. Serialize pings within a tab and make established-cookie writes idempotent.

Metric definitions

Implementation assumption: visitors are distinct guest or signed-in browsers per UTC day; DAU is distinct verified signed-in accounts with foreground activity, including accounts with no saved profile. This is a stated implementation choice, not a recorded user approval.
