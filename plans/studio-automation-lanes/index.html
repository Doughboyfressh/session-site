Studio multi-parameter automation

implementation activestudio-automation-lanes · 2026-09-28 · annotate below, then hit “Save annotations”

Goal

Give producers and engineers a DAW-grade automation workflow inside SESSION: select a channel parameter, draw or drag breakpoint envelopes, choose smooth or hold transitions, copy lanes between tracks, and hear the same automation in playback, loops, stems, mixdowns, recovery, and shared project merges. The release succeeds when automation is sample-timed, mobile-editable, reversible as one Undo step per gesture, and survives saving and collaboration safely.

Non-goals

  • Third-party VST, AU, AAX, or CLAP plug-in hosting; browsers cannot safely host native desktop plug-ins.
  • Bezier tension handles, tempo maps, and recording live knob movements; these follow after the core lane model is proven.
  • Automation for topology-changing controls such as compressor bypass or effect type in this slice.

Screens & flows

Duplicate a card per screen or flow. Sketch the shape in words; wireframes can come later.

Automation lane editor

Select Volume, Pan, Low/Mid/High EQ, Reverb, or Delay. Click the graph to add a point, drag points to reshape the lane, and choose Linear or Hold transitions with beat-grid snapping.

Precision point controls

Edit exact time and value, step through points, delete one point, clear a lane, or copy and paste the current lane to another track.

Arrangement awareness

Track clips show how many automation lanes are active; the automation graph follows the transport playhead and clearly explains whether a lane multiplies or replaces the channel control.

Risks

HIGHScheduled AudioParam events can diverge between live playback and offline export. Use one shared scheduler and verify the event sequence at multiple start positions and loop boundaries.
HIGHDrag updates can create dozens of Undo entries or race collaborative saves. Keep drag previews local, commit once on pointer-up, and pause sync while a gesture is active.
MEDSeven lanes across 48 tracks can exceed save limits. Cap each lane at 64 points and each track at 256 total points; retain the existing project-size gate.
MEDLegacy projects store volume automation in a separate field. Read it as the volume lane until the user edits or clears that lane, without rewriting old saves implicitly.
