# SESSION UI audit — October 2, 2026

This pass inspected the live guest workspace on desktop and mobile, then used local fixtures for member conversations and editing operations. The earlier banner and navigation fixes remain in place. No production accounts, messages, or projects were changed by verification.

| Defect                                    | Verified behavior before correction                                                                                                        | Correction                                                                                                                                            |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| Originals missing from feed search        | Searching `ambient` first showed two Originals, then server results replaced them with “No tracks matched.” Beat library still found them. | Merge local Originals with community results, deduplicate IDs, and retain them during loading or failure.                                             |
| Search response races and failed searches | An older request could replace the results or loading state for a newer query; HTTP failures left old results without an explanation.      | Abort obsolete requests, reject late responses, clear prior-query results immediately, and show an accessible error and retry action.                 |
| Archived search and trending hits         | Rows absent from the newest 200 initial tracks could not open.                                                                             | Use the existing authorized `/t/<id>` permalink for those records; loaded tracks still open their existing detail dialog.                             |
| Creator service details                   | Search returned partial creator objects without location, services, or payment eligibility, so their dialog differed from People.          | Export the same explicit public service fields and eligibility flag; private profiles and account IDs remain excluded.                                |
| Drum editor Undo/Redo                     | Applying Analog machine, then Undo, restored the score but left Analog selected and Apply enabled.                                         | Reset the draft when the committed drum score changes, while preserving it through unrelated name, mix, waveform, and tempo updates.                  |
| Automation gesture interruption           | Leaving the editor during a drag or losing pointer capture could leave Studio's editing lock active.                                       | Cancel interrupted gestures, release capture/listeners, and report inactivity; completed gestures still commit once.                                  |
| Collaboration alert target                | Opening an alert ignored its conversation ID and selected the inbox's default conversation.                                                | Resolve the target only against the member's authorized inbox and select its incoming or sent folder.                                                 |
| Incoming conversation updates             | Peer replies and status changes did not appear while the same conversation stayed open.                                                    | Refresh visible inbox/thread reads every ten seconds and on focus/visibility return, preserving drafts and rejecting stale reads or action responses. |

## Verification

The offline runner includes actual-component regressions for drum drafts, automation gestures, and conversation lifecycle, plus search cancellation/merge and actual search-route public-field tests. Browser fixtures are `tests/community-search-harness.html`, `tests/automation-editor-harness.html`, `tests/social-ui-harness.html`, and the existing Studio fixture `tests/ui-defects-harness.html`. They simulate delayed reads and member data locally and never forward action requests to production.

The creator query passed the actual route against an in-memory SQLite database and a read-only EXPLAIN on PostgreSQL in the configured SESSION database. The public profile field list excludes Stripe account IDs and private profiles. No schema or authorization change was required.

Recorded evidence is under ignored `outputs/ui-audit-evidence`. CLI e2e is separate from browser acceptance. Desktop viewport checks and synthetic member data do not certify physical mobile devices or cross-network live calls.

## Remaining inventory finding

Saved tracks can omit a still-public saved upload once it falls outside the newest 200 tracks returned by `/api/state`. The saved IDs remain present, but that screen filters only loaded track records. This predates the changes above and needs a bounded saved-track pagination or hydration design; the new search/permalink behavior provides another path to open the upload. No unbounded expansion of workspace state was introduced in this pass.
